# 🏢 Elements Luxury Apartment - Swipe Landing Page Showcase

Landing page portofolio hasil retouch foto interior HDR yang siap di-deploy ke **Vercel Free Hosting**.

## 🌟 Fitur Utama
- **Model Swipe (Touch Gesture)**: Menggunakan Swiper.js untuk swipe kanan-kiri yang mulus di HP / Touchscreen / Desktop.
- **Slider Pembanding Sebelum vs Sesudah (Before vs After)**: Handle geser interaktif untuk membandingkan pencahayaan asli vs retouch.
- **Kategori Filter Ruangan**: Filter cepat (*Living Room, Bed Room, Bath Room, Kitchen & Dining, Patio*).
- **Gambar Teroptimasi Web (WebP & JPG)**: Loading super cepat pada jaringan mobile.
- **Modal View & High-Res Viewer**: Klik untuk melihat perbandingan layar penuh.
- **Glassmorphism & Aesthetic UI**: Tampilan modern luxury dengan tema gelap premium.

## 🚀 Cara Deploy ke Vercel Free Hosting (3 Cara Mudah)

### Cara 1: Menggunakan Vercel CLI (Paling Cepat)
1. Buka PowerShell / Terminal di folder project ini:
   ```bash
   C:\Users\agusy\.gemini\antigravity\scratch\elements-landing-page
   ```
2. Jalankan perintah:
   ```bash
   npx vercel
   ```
3. Ikuti petunjuk di layar (tekan Enter untuk opsi default).
4. Selesai! Anda akan langsung mendapatkan link domain gratis seperti `https://elements-retouch-showcase.vercel.app`.

---

### Cara 2: Upload via Drag & Drop di Website Vercel
1. Buka [https://vercel.com](https://vercel.com) dan login/daftar akun gratis.
2. Masuk ke Dashboard Vercel -> Klik tombol **Add New** > **Project**.
3. Drag & drop folder `elements-landing-page` ke halaman Vercel.
4. Klik **Deploy**.

---

### Cara 3: Connect via GitHub
1. Upload folder `elements-landing-page` ini ke repository GitHub Anda.
2. Di Vercel, pilih **Import Git Repository**.
3. Klik **Deploy**. Vercel akan otomatis meng-host website setiap ada update code!
